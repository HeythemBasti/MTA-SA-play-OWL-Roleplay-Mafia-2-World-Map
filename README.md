 # MTA:SA Mafia World

A custom **Multi Theft Auto: San Andreas (MTA:SA)** map project that transforms the original GTA: San Andreas world into a **Mafia-inspired environment**.

The project keeps the original **GTA:SA characters and MTA:SA gameplay**, while replacing the game's world with custom buildings, streets, interiors, and environmental assets inspired by classic Mafia-style cities.

## 🎮 Features

* 🏙️ Mafia-inspired city environment
* 🏢 Custom buildings and streets
* 🚗 Designed for MTA:SA
* 👤 Keeps GTA: San Andreas character models
* 🗺️ Replaces the original San Andreas environment
* 🎭 Suitable for Mafia/crime roleplay servers
* 🛠️ Custom TXD/DFF map assets
* 🌆 Inspired by the atmosphere and architecture of **Mafia 2**
* 🎮 Suitable for an **Owl Roleplay-style** experience

## 🔧 Installation

1. Download or clone this repository.
2. Copy the map/resource files into your MTA:SA server's `resources` folder.
3. Add the resource to your server configuration.
4. Start the resource from the MTA server console.
5. Launch MTA:SA and explore the new Mafia-inspired world.

## 🎨 Concept

The goal of this project is to create a **Mafia-style world inside GTA: San Andreas**, rather than simply adding a few Mafia-themed objects.

The original San Andreas world is progressively replaced with custom assets to create a completely different setting while maintaining the familiar GTA:SA character models and MTA:SA multiplayer framework.

## 📺 Inspiration

The project uses workflows inspired by **Mafia 2 asset extraction/export**, including the process of converting and adapting game environment assets for use in other projects.
